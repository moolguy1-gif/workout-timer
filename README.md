# 운동 타이머 (PWA)

근력 운동 휴식 시간 · 인터벌 운동 · 스톱워치를 위한 오프라인 지원 웹 앱입니다.

## 기능
- **휴식 탭**: 시간을 설정하고 세트 사이 휴식을 잽니다. 버튼을 누르면 카운트다운이 시작되고, 시간이 끝나면 진동+소리로 알려줍니다. 버튼을 다시 누르면 설정한 시간으로 되돌아갑니다(0초 리셋 아님).
- **인터벌 탭**: 고강도/중강도/저강도 등 여러 단계를 자유롭게 추가·수정하고, 전체 반복 횟수를 설정할 수 있습니다. 시작하면 단계가 끝날 때마다 자동으로 다음 단계로 넘어가며 알림이 울립니다.
- **스톱워치 탭**: 기본적인 시작/정지/랩/리셋 기능.
- 화면이 꺼지지 않도록 Wake Lock 적용(운동 중 화면 유지).
- 설정값(휴식 시간, 인터벌 단계 구성)은 기기에 자동 저장됩니다.
- Service Worker로 오프라인에서도 완전히 동작합니다.

## 설치 방법 (안드로이드)

### 방법 A. 가장 빠른 방법 — 웹앱으로 홈 화면에 추가 (권장, APK 불필요)

1. 아래 "GitHub Pages로 배포하기"를 따라 무료로 이 앱을 인터넷에 올립니다.
2. 안드로이드에서 **Chrome**으로 배포된 주소에 접속합니다.
3. Chrome 우측 상단 점 3개 메뉴 → **"홈 화면에 추가"** (또는 "앱 설치") 선택.
4. 홈 화면에 아이콘이 생기고, 이후에는 인터넷 없이도 완전히 오프라인으로 작동합니다.

이 방법만으로도 실제 설치된 앱과 거의 동일하게 동작합니다 (전체화면, 아이콘, 오프라인 지원).

### 방법 B. 진짜 APK 파일로 만들기 (PWABuilder 이용)

방법 A까지 완료했다면(즉, 앱이 실제 URL로 배포되어 있다면):

1. https://www.pwabuilder.com 접속
2. 배포한 앱 주소(예: `https://내아이디.github.io/workout-timer/`)를 입력하고 **Start**
3. PWABuilder가 manifest와 Service Worker를 자동으로 인식합니다 (모두 초록불이면 정상)
4. **Package for stores** → **Android** 선택 → 옵션 기본값 그대로 두고 **Generate**
5. 다운로드된 `.apk`(또는 `.aab`) 파일을 안드로이드 폰으로 전송
6. 폰에서 파일을 열어 설치 (최초 1회 "출처를 알 수 없는 앱 설치 허용" 설정 필요 — 설치 시 안내가 뜨면 그대로 따라가면 됩니다)

## GitHub Pages로 배포하기 (무료, 5분)

1. https://github.com 에서 계정 생성/로그인
2. 우측 상단 **+** → **New repository** → 이름 예: `workout-timer` → Public으로 생성
3. 이 폴더 안의 파일 전체(`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `icons/` 폴더)를 리포지토리에 업로드
   - GitHub 웹사이트에서 "Add file" → "Upload files"로 드래그 앤 드롭 가능 (git 명령어 몰라도 OK)
4. 저장소의 **Settings** → **Pages** 메뉴로 이동
5. **Source**를 `Deploy from a branch`로, Branch를 `main` / `/(root)`로 설정 후 저장
6. 1~2분 후 `https://내아이디.github.io/workout-timer/` 주소가 활성화됩니다

이 주소를 방법 A(홈 화면 추가) 또는 방법 B(PWABuilder)에서 그대로 사용하면 됩니다.

## 로컬에서 미리 확인하고 싶다면

폴더 안에서 아래 명령어로 간단히 로컬 서버를 켜고 PC 브라우저로 확인할 수 있습니다.

```
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 접속.
(단, Service Worker와 홈 화면 추가는 실제 HTTPS 주소 — 또는 localhost — 에서만 정상 동작합니다.)
